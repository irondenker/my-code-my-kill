# Third-Party Notice Entry Template

Use one entry per third-party dependency, template, font, or asset.

```md
### Entry: <component name>

- `status`: verified | unverified | replaced
- `component`: <local path or feature scope>
- `upstream author`: <person/org>
- `upstream source`: <URL>
- `license`: <license id/name + link>
- `local modifications`: <what changed in this repo>
- `required attribution`: <exact text or file placement requirement>
- `required license copy`: <yes/no + where stored>
- `compliance notes`: <special terms, trademark, NOTICE, etc.>
- `reviewed on`: <YYYY-MM-DD>
- `reviewed by`: <name>
```

## Quick Checklist

- Source URL is exact and reachable.
- License is identified and archived when required.
- Attribution text is preserved where required.
- Distribution obligations (NOTICE, license text, trademarks) are met.
- Entry reviewer/date are filled.
