# Commit Emoji Guide

## 예시

`♻️ Refactor: Move 'article-helper' file into 'controller.article' folder`

## 작성 요령

`[emoji][commit message]: (변경 사항, 영문으로 작성 & 첫 글자는 대문자고 나머지는 소문자 위주로 평이하게 작성)`

| emoji | commit message | when to use it |
| :---: | :------------: | :------------: |
| 🎉 | Start | 프로젝트 시작 |
| ✨ | Feat | 새로운 기능 추가 |
| 🐛 | Fix | 버그 수정 |
| ♻️ | Refactor | 코드 리팩터링 |
| 💄 | Style | 스타일 추가 및 업데이트 |
| 📦 | Chore | 패키지 추가 및 업데이트 |
| 📚 | Docs | 그 외 문서 추가 및 업데이트 |
